# Simulation Artifact Index

These files form the course's no-install, no-paid practice lane. All people,
tasks, credentials, systems, and results are synthetic. JSON and Markdown files
are inert course fixtures; nothing here connects to a network or service.

Follow the [Simulation Path](../../docs/course/simulation-path.md) and inspect
artifacts in its stated order.

| Artifact | Course use |
| --- | --- |
| `project-brief.md` | Goal, context, constraints, and claim classification |
| `before/task-data.json` | Known starting data |
| `session-transcript.md` | Narrated gather, act, verify session |
| `permission-prompts.md` | Mock action decisions and dispositions |
| `changes.patch` | Reviewable proposed change |
| `after/task-data.json` | Changed synthetic data |
| `after/summary.json` | Corrected expected result |
| `verifier-transcript.txt` | Baseline, useful failure, and corrected pass |
| `context/CLAUDE.md` | Durable project context to critique |
| `skill/SKILL.md` | Mock reusable review procedure |
| `skill/example-output.md` | Comparison output, opened after attempting |
| `mcp/tool-manifest.json` | Mock tool capabilities |
| `mcp/tool-transcript.json` | Mock tool calls and untrusted results |
| `hooks/policy.json` | Human-readable simulated hook policy |
| `hooks/events.json` | Events whose outcomes learners predict |
| `hooks/transcript.txt` | Recorded mock policy outcomes |
| `team/team-plan.md` | Parallel-work and integration scenario |
| `team/reviewer-report.md` | Reviewer finding opened after prediction |
| `release/release-checklist.md` | Private/public handoff and recovery plan |

Do not claim that these records came from your machine. In submitted work,
write **Evidence mode: SIMULATED** and distinguish your decision from the
supplied outcome.
