# Finish and Save Before Review

Worked patterns are useful for feedback and revision, but seeing them before a
first attempt changes what the attempt measures. This page is a deliberate pause,
not an access control.

Before continuing:

1. Finish the diagnostic or chapter checkpoint without using worked patterns.
2. Save or export the original response so later edits do not replace the baseline.
3. Record the date, lane, tools, people, references, accessibility or language
   support, and AI assistance used.
4. Record this disclosure exactly:

```text
Worked answer patterns viewed before first attempt: yes / no / unsure
If yes or unsure, what was viewed:
```

If the answer is yes or unsure, continue. The work remains useful for feedback,
but describe the baseline as **pattern-exposed** rather than an exposure-free
measure. Do not restart merely to erase the disclosure.

The [Scoring Guide](scoring-guide.md) contains public criteria and is safe to use
before or during the task. After the steps above are complete, open the
[Answer Key and Evidence Guide](answer-key.md) to self-score, seek peer feedback,
and revise. Preserve both the original and revised versions.
