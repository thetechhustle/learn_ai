# Chapter 6: Everyday Workflows — Build Real Things

This chapter applies the foundations and context work to repeatable workflows: driving sessions with controls, taking an idea to a reviewable site, debugging systematically, and applying the same loop to writing, research, planning, and administration.

This is also where your Lesson 1.4 build list stops being a list.

!!! abstract "What you will learn"
    - Drive sessions with the slash commands and shortcuts that pros lean on.
    - Run the idea-to-live-site workflow end to end, repeatably.
    - Debug systematically: reproduce, isolate, fix, prove — with the agent doing the legwork.
    - Apply agentic workflows to non-code work: documents, research, planning.
    - Build your first true automation — work that happens without you.

!!! success "Builder principle"
    Tools become skills through repetition on real work. This chapter is deliberately repetitive — that's the design.

!!! example "Watch with this chapter"
    - [Mastering Claude Code in 30 Minutes](https://www.youtube.com/watch?v=B_KAEqiC-0Q) — final assigned viewing; by now you should be nodding along, not taking notes.
    - [How I use LLMs](https://www.youtube.com/watch?v=EWvNQjAaOHw) — Karpathy. Rewatch the daily-workflow segments with your new eyes.

## Real talk

Somewhere in this chapter, it clicks. Not "I understand agents" — that happened chapters ago. This click is quieter and bigger: *"oh, this is just how I work now."* The moment you catch yourself reaching for a session the way you reach for a browser tab — that's the shift the whole course was built to cause. It tends to happen mid-chapter-6. Watch for it.
